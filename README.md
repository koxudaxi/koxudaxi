## 🛠️ [datamodel-code-generator](https://github.com/datamodel-code-generator/datamodel-code-generator) [![PyPI downloads](https://img.shields.io/pypi/dm/datamodel-code-generator?label=PyPI%20downloads)](https://pypistats.org/packages/datamodel-code-generator)
- I created it in [2019](https://github.com/datamodel-code-generator/datamodel-code-generator/commit/153b5672ee1f52a766a4a433507fcd02aae0f2d8) and have been its lead maintainer since
- Generates Pydantic v2 `BaseModel`, Pydantic v2 `dataclass`, `dataclasses`, `TypedDict`, and `msgspec.Struct` from OpenAPI, JSON Schema, GraphQL, and other schemas
- Since 0.84, also generates FastAPI server and HTTP client packages
- Also documented for AI coding agents: [llms.txt](https://datamodel-code-generator.koxudaxi.dev/llms.txt) and a [coding-agent skill](https://github.com/datamodel-code-generator/datamodel-code-generator/blob/main/docs/coding-agent-skill.md)
- Used by [openai/codex](https://github.com/openai/codex/blob/205d37a20f742b0bf8e191622bd07c43f567ea49/sdk/python/scripts/update_sdk_artifacts.py#L558-L590) (Codex SDK), [modelcontextprotocol/python-sdk](https://github.com/modelcontextprotocol/python-sdk/blob/c9356a2a8fb805ac2202e44c05371cf005edc923/scripts/gen_surface_types.py), [apache/airflow](https://github.com/apache/airflow/blob/f1ac27af8b53e7d3ca7ff710c4f4413599bd1535/airflow-ctl/pyproject.toml#L148-L172), and [more](https://github.com/datamodel-code-generator/datamodel-code-generator#-projects-that-use-datamodel-code-generator)
